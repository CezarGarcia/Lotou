Estado final, não diferença: cada entrada leva o estoque que sobrou, e não “menos 2”. Aplicar a mesma entrada duas vezes dá o mesmo resultado.
O redis_seq guarda a posição no stream: o consumidor nunca aplica uma entrada mais antiga por cima de uma mais nova.
