Uma tarefa, um worker, uma vez

O exchange recebe a mensagem e, pela routing key, decide em que fila ela entra. Um worker pega a mensagem, faz o trabalho e confirma. Só então ela sai da fila.

Tipos de exchange: direct entrega pela chave exata, topic aceita padrões (email.# pega todo e-mail) e fanout entrega para todas as filas ligadas.
Prefetch é quanto o worker segura de uma vez. O PDF usa 1, porque é pesado; o e-mail usa 10, porque passa o tempo esperando a rede.
Worker caiu antes do ack? A mensagem volta para a fila e outro worker a pega. A recusada, ou vencida pelo TTL, vai para o exchange de mortos.
